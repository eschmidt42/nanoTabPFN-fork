# nanoTabPFN-fork

> Fork of the [nanoTabPFN repo](https://github.com/automl/nanoTabPFN).

## Prerequisite

[uv](https://docs.astral.sh/uv/#installation) is available.

## Setup

```bash
uv sync
```

## Notebooks

The core pieces to train a single `NanoTabPFNModel` can be found in the [getting-started notebook](./notebooks/getting-started.ipynb).

The [experiment.ipynb](./notebooks/experiment.ipynb) is based on the identically named notebook the authors of the original repo provided. Their code was refactored, some tools migrated and the list of baseline models extended.
